# Paradise Nursery - Online Plant Shopping Application

Welcome to **Paradise Nursery**, an interactive e-commerce web application built for houseplant enthusiasts! This application allows users to browse an extensive catalog of indoor plants, learn about their unique benefits, manage their shopping cart, and calculate costs dynamically in real time.

## Project Overview

Paradise Nursery is designed to bring nature closer to your home. Whether you are looking for air-purifying foliage, aromatic fragrant plants, or natural medicinal flora, Paradise Nursery provides a seamless shopping experience.

## Key Features

- **Landing Page & About Us**: Vibrant landing page featuring background imagery, brand story, and a "Get Started" button.
- **Product Catalog**: 18 unique houseplants categorized across 3 categories (*Air Purifying*, *Aromatic Fragrant*, and *Medicinal Plants*).
- **Dynamic Header & Navigation**: Sticky navbar present on both product listing and cart views with a real-time cart item badge counter.
- **Shopping Cart Management**: Add, remove, update quantities, subtotal calculations, and total cart cost calculation.

## Technology Stack

- **Frontend**: React (Vite / CRA)
- **State Management**: Redux Toolkit (`@reduxjs/toolkit` & `react-redux`)
- **Styling**: CSS3 with modern design principles (flexbox, grid, glassmorphism)
